Humming[bird]Tech website

This is a static GitHub Pages site. Keep the HTML, CSS, JavaScript, CNAME,
.nojekyll, and html/repos.json files in the repository root/folder structure.

Recent interface updates:
- Normal, Dark, and Light appearance modes, with independent background choices.
- Plain white, forest, midnight, slate, sunrise, and custom backgrounds.
- Settings for corner radius, liquid-glass opacity/blur, accent color, and text size.
- Lightweight mode disables animated backgrounds, transitions, shadows, filters,
  and backdrop blur; nonessential diagnostics and pointer effects are not loaded.
- Games are rendered 100 cards at a time. More cards are added on request.
- The game catalog cache stores compact card metadata; game file trees are fetched
  only when the user explicitly downloads a game's ZIP.
- Shared navigation, a configurable right-click menu, and the Padlet community embed.

Preferences are stored locally in the browser. The Padlet discussion and games
catalog require an internet connection.

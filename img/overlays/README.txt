Google Classroom emergency overlay

The Classroom disguise is rendered as HTML by global-utils.js.
Teacher cards default to the name Nicole Librearski. The name, five avatar-circle colors, and an optional uploaded circle image can be changed in Settings → Emergency disguise → Further optimization.
Without an uploaded image, the circles show the teacher's initials. No external portrait service is used.

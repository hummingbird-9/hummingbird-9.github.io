Stockfish.js 19.0.1 — browser engine attribution

This site uses the unmodified Stockfish.js 19.0.1 lite, single-threaded WebAssembly engine by Nathan Rugg, Chess.com, LLC, and contributors. The JavaScript worker is stored in this directory. The matching WebAssembly file is fetched lazily from the pinned npm release:
https://cdn.jsdelivr.net/npm/stockfish@19.0.1/bin/stockfish-19-lite-single.wasm

Upstream browser engine and corresponding source:

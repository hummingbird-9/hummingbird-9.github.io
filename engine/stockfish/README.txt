Stockfish.js 19.0.1 — browser engine attribution

This site uses the unmodified Stockfish.js 19.0.1 lite, single-threaded WebAssembly engine by Nathan Rugg, Chess.com, LLC, and contributors. The JavaScript worker and its matching WebAssembly binary are stored together in this directory and served directly by GitHub Pages. A repository GitHub Actions workflow downloads the pinned release and verifies its SHA-256 before committing the WASM binary.
